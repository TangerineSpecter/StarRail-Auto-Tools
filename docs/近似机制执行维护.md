# 条款拆解与近似执行（开发中）

此层与 `catalogue-rules.json` 的精确计算隔离，不改变站街、培养方案、行动轴或账号数据库。

## 当前入口

- `npm run compile:mechanisms`：遍历完整来源，生成独立定义与报告。
- `npm run compile:mechanisms -- --check`：检查重复生成是否一致。
- `npm run sync:all -- --skip-images`：来源任务与编译依次在隔离候选目录执行，全部成功后同批发布 JSON。
- `npm run sync:catalog -- mechanisms`：仅对已有来源重新编译；原有独立来源脚本仍可执行。
- `explainAbility`：校验来源指纹、实体身份和准确等级，解释条款与参数。
- `executeScenario`：显式实体输入、带种子 PRNG、基础线性伤害/治疗/护盾、局部跳过及 1000 次操作上限。

JSON 候选之间共享前序结果；抓取、转换或编译失败不发布任何候选。图片不属于 JSON 事务；发布具备进程内 I/O 失败恢复，不保证跨进程崩溃原子性或多进程写隔离。

发布清单只包含相对初始快照实际改动的候选文件，不会用未改动的副本覆盖人工文件。发布前发现目标文件同期被修改、删除或创建时，中止整批发布并保留正式文件。该检测不等同于跨进程文件锁。

## 不把索引覆盖当作语义完成

所有能力都会遍历，原文按位置切分，参数引用与带位置常量单独记录；未展示参数原样保留。空描述列入 `missingDescriptions`，不制造占位效果。

当前仅接受明确的属性×倍率线性表达式。多倍率、未编译门控、装备、行迹、星魂及未知操作明确跳过。有条款记录不意味着语义拆解或执行完成；`semanticCoverageComplete` 保持 false。

编译器 v2 只接受已知动作起始模板，未解析条件及后续依赖句保守跳过；因此可执行覆盖可能下降，不以放宽门控提高覆盖数字。两种属性/倍率语序均保留固定加值。随机我方与随机敌方目标均逐次从存活同阵营实体中 roll，记录种子与采样值；专用结算被跳过时也保留随机记录。弹跳次数等未实现的行为仍明确列入限制。

直伤仅包含基础倍率、等级防御项和抗性项；治疗/护盾仅为基础量。未注册的专用策略仅解释基础量，不修改生命。结果记录缺项，不能冒充完整结算。没有默认账号状态；非法身份、等级、属性或失效指纹报错。

精确审核仍查看 `catalogue-audit-report.json` 与独立严格门禁，近似报告不推断或续审精确规则。
