# iPhone Duo 内容页重构与验收（2026-11-10）

## 范围与边界

本轮重构背包、图鉴、毕业、配队、同步五个移动内容页，保留已确认的菜单位置、`device-posture.ts` 与原生 WebView 配置。桌面页面继续直接显示完整工具，只有移动入口注入 `mobileViewKey` 后才启用按需展开。数据查询、角色 ID、装备绑定、评分规则与同步协议均沿用原接口。

移动内容样式集中在 `src/mobile/content.css`，只由移动入口同步加载。`mobile.css` 保留壳层和导航坐标；原来位于其中的桌面组件适配规则已经迁出，避免多套覆盖互相抵消。

## 五页设计

| 页面 | 首屏任务                       | 次级信息与交互                                                            | 展开屏                                     |
| ---- | ------------------------------ | ------------------------------------------------------------------------- | ------------------------------------------ |
| 背包 | 分类、搜索、筛选入口、实际列表 | 评分与排序默认折叠；打开后保留选项；筛选有明确关闭按钮；分页沿用原行为    | 遗器/光锥卡片可并排；角色按可用宽度分列    |
| 图鉴 | 单行分类与卡片内容             | 角色/光锥筛选收起时显示已选条件；Tab 内部可横向滚动；窄屏隐藏重复分类计数 | 角色、光锥多列；套装双列；详情保持可读宽度 |
| 毕业 | 角色、达标情况、综合完成与短板 | 装备、目标、词条与潜力按角色展开；搜索、排序保持可用                      | 多个角色可并排；每张卡片自身保持纵向阅读   |
| 配队 | 搜索与成员构成                 | 明确空位、等级、毕业度及备注；错误可重试                                  | 成员根据卡片宽度分列，多个队伍可并排       |
| 同步 | 当前配置状态与下载动作         | 保留服务器、目录、用户名、密码表单和浏览器必填校验；下载中禁止修改连接    | 状态/动作与连接配置并排                    |

内容断点基于 `.mobile-content` 的容器宽度，而非整块屏幕宽度。440px 后开放较紧凑的双列，680px 后开放宽内容布局；侧栏、安全区或窗口缩窄会直接减少实际可用空间。主要控件至少 44px 高，输入框使用 16px 字体，数字使用等宽数字；减少动态效果偏好有对应处理。

## 半折叠的真实区域

依据 [Apple 自适应布局说明](https://developer.apple.com/videos/play/tech-talks/111463/) 与 [准备 Duo 应用](https://developer.apple.com/videos/play/tech-talks/111461/)，通过新增移动 command `get_mobile_layout_regions` 在 UIKit 主线程查询 `reservedRegionsOfKind:`。只使用系统返回的活动 division 区域，不把屏幕尺寸当作折叠角度。

- 书本式：卡片分布在折痕两侧，分类和工具栏留在一个区域内；详情限制在右侧可用正文区域，避开系统状态栏共享列。
- 桌面式：连续滚动内容保持自然流动，详情/筛选落在折痕下方；缩短详情头图，避免首屏只有装饰。
- 平展、旧系统或不支持查询的环境：回到普通容器响应式布局。
- 轮询仅在页面可见时运行，每 500ms 至多一个请求，补足折叠角度改变却没有 resize 的情况；卸载会清理监听、定时器和 CSS 变量。

native 坐标按照 WebView bounds 与 CSS viewport 比例换算。弹层宽度取正文右边缘而非整个屏幕右边缘，防止关闭按钮进入时间/Wi-Fi 区域。导航姿态与内容折痕使用不同属性，内容变化不重挂载页面。

## 布局与交互 review

发现并已修正：

1. 图鉴旧 `flex-wrap` 与 `justify-content` 导致窄屏分类换行或左侧被挤出：移动分类固定单行，按需横向滚动，窄屏隐藏计数。
2. 遗器副词条可越过卡片边界：采用可缩小的两列网格，数值保留独立宽度，文字必要时省略。
3. 空背包沿用桌面 350px 固定高度：移除固定高度，以实际空状态内容决定卡片高度。
4. 筛选面板没有手机上明确可见的关闭入口：增加移动专用关闭按钮，保留重置与查看结果。
5. 详情弹层未考虑 Teleport、折痕及系统共享列：针对每一种详情 portal 独立约束区域，原生模拟器检查了关闭按钮的位置与点击。
6. 半折叠下复用顶部安全区导致弹层内部出现大块空白：下方弹层不重复应用顶部 inset。
7. 桌面遗留的文字阴影、小字号和非等宽数字：移动内容覆盖为更清晰的文字与数值排版。

## 移动端开发示例数据（2026-11-11）

- `--mode mobile` 的 Vite 开发入口默认启用示例数据，iOS 模拟器与浏览器共用应用内适配器，无需再注入外部测试脚本。
- 顶部“示例数据 / 真实数据”按钮切换后刷新页面，选择保存在当前 WebView 的 localStorage 中。真实模式继续使用原生数据库和同步连接。
- 示例包含 60 件遗器、20 个角色（含三月七、开拓者的不同命途）、16 个光锥、8 份培养方案、3 支配队；支持分页、搜索、筛选、详情、装备和图鉴目标统计。
- 示例模式仅在内存中提供数据，所有未支持的业务操作（包括保存连接、同步和删除）均明确拒绝，不回落到真实数据库。原生折叠区域查询继续透传。
- 桌面入口不安装适配器。正式移动端构建通过 `import.meta.env.DEV` 移除适配器、示例数据与切换按钮，不影响正式包及已有档案。
- 已在当前 iPhone Duo 模拟器开发 App 中观察到“示例数据”标记和 60 件遗器；浏览器检查列表、详情、培养、配队、图鉴和模式切换。
