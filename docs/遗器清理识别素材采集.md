# 遗器清理识别素材采集

## 用途与安全边界

这些截图用于校准遗器分解页的页面锚点、网格位置、选中边框、锁定/装备标记和最终确认弹窗。原始截图只用于测试与模板生成，不会进入安装包。

在模板通过回归测试前，软件会将模板状态保持为 `calibrated: false`。预览只保存异常截图，清理执行被安全锁阻止；不要手工修改派生清单绕过此限制。

## 存放目录与命名

将未经缩放、裁剪或压缩的 PNG 放到：

```text
tests/fixtures/relic-cleanup/raw/
```

文件名格式：

```text
语言__客户区分辨率__窗口模式__Windows缩放__页面状态__选择状态__序号.png
zh-CN__1920x1080__fullscreen__100pct__salvage-grid__none-selected__001.png
```

字段只能使用以下值：

- 窗口模式：`windowed`、`fullscreen`
- Windows 缩放：`100pct`、`125pct`、`150pct`
- 选择状态：`none-selected`、`one-selected`、`multi-selected`、`not-applicable`
- 序号：三位数字，从 `001` 开始

截图必须只包含游戏客户区，不能包含软件窗口、桌面、UID 水印之外的个人信息。若游戏内显示 UID，可先在提交前告知维护者，由模板脚本避开该区域；不要自行涂抹 UI 锚点附近内容。

## 必采页面

每组分辨率/模式/DPI 至少采集以下状态：

1. `salvage-grid`：分解选择页空闲画面，分别采集未选中、单选和多选。
2. `relic-detail`：打开 5 星遗器详情；覆盖六个部位、0/3/6/9/12/15 等级、不同主副词条。
3. `locked-relic`：至少一件带锁定标记，并打开其详情。
4. `equipped-relic`：至少一件带装备角色标记，并打开其详情。
5. `scroll-middle`：列表滚动到中部并完全停止。
6. `scroll-bottom`：列表滚动到底部，最后一行不足一整行时也要采集。
7. `sort-popup`：排序/筛选弹层展开。
8. `final-confirm`：已选择遗器后的最终分解确认弹窗；不要点击确认。
9. `confirm-cancelled`：从最终确认弹窗取消后回到选择页。
10. `loading`：页面切换或滚动加载中的画面。
11. `occluded`：通知、鼠标提示或其他游戏内浮层遮挡关键区域。
12. `wrong-page`：背包页、角色页等容易误判但不是分解选择页的页面。

同一画面如存在动画、不同背景亮度或鼠标悬停效果，请额外采集 2～3 张。

## 最低覆盖矩阵

必须覆盖以下客户区分辨率：

- 1280×720、1920×1080、2560×1440（16:9）
- 1280×800、1920×1200（16:10）

每个分辨率至少包含 `windowed` 和 `fullscreen`。Windows 显示缩放需要整体覆盖 `100pct`、`125pct`、`150pct`；若某个组合游戏无法提供原生客户区尺寸，在同分辨率相邻组合的说明文件中记录原因，不要拉伸截图伪造。

## 提交前检查

在项目根目录运行：

```powershell
python scripts/generate-relic-cleanup-templates.py --audit
```

脚本会检查命名、PNG 完整性、尺寸字段与实际像素是否一致，并输出缺失矩阵。素材齐备后，由维护者在 `tests/fixtures/relic-cleanup/calibration-regions.json` 标注稳定区域，再运行：

```powershell
python scripts/generate-relic-cleanup-templates.py --generate
```

派生文件会写入 `src-tauri/assets/relic-cleanup/zh-CN/`，包含模板 PNG、SHA-256、参考尺寸和阈值。该目录内除初始未校准清单外的内容均由脚本生成，禁止手工修改。

## 识别验收门槛

- 所有正确分解页必须通过至少两个独立锚点。
- `wrong-page`、`loading`、`occluded` 不得通过完整页面验证。
- 验证集中不得出现错误遗器被标记为“唯一匹配”。低置信度应进入异常目录。
- 选中边框、选中数量变化和最终确认弹窗必须分别有独立验证信号。
- 完成 Windows 人工回归并记录结果后，才允许生成 `calibrated: true` 的模板清单。
