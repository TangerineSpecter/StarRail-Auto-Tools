# 数据同步

## 用途与配置

在“软件设置 → 数据同步站”选择协议（WebDAV / FTP / SFTP），填写对应连接信息。应用不会自动创建远端目录，请先在服务器或 NAS 上建好目录。

| 协议   | 必填项                                             | 默认端口    | 说明                                                                                                                             |
| ------ | -------------------------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------- |
| WebDAV | 服务器地址、远端同步目录、用户名、密码             | 由 URL 决定 | 目录必须以 `/` 开头，例如 `/StarRailTools/`                                                                                      |
| FTP    | 主机、远端同步目录、用户名、密码                   | 21          | 可选「使用 FTPS (TLS)」，为显式 AUTH TLS。加密但不校验证书，便于自签 NAS。不支持隐式 FTPS（端口 990）。目录填 `/` 表示账号根目录 |
| SFTP   | 主机、远端同步目录、用户名；密码或私钥路径至少一种 | 22          | 填写私钥时，密码当作私钥口令，可留空。目录填 `/` 表示账号根目录                                                                  |

连接信息仅保存在本机应用数据目录的 `sync-settings.json`，不写入同步文件。读取时兼容两类历史配置：只有 WebDAV 的旧文件 `webdav-settings.json`（迁移后保留原文件），以及曾把协议写成 `webDav` 的中间版本 `sync-settings.json`（会改写成 `webdav`）。密码按当前版本以该本地 JSON 配置保存，因此应使用受操作系统账户保护的设备，并妥善保管应用数据目录。

SFTP 首次连接会把服务器主机密钥指纹记在本机 `sftp-known-hosts.json`。之后若密钥变化，同步会失败；确认仍是同一台服务器后，删除该文件再试。

“测试连接”会验证认证，并能进入远端同步目录；远端数据文件尚不存在时也视为连接可用。点击“上传本地数据”会写入完整快照；点击“下载并覆盖本地”后必须确认，成功时会以远端快照完全替换本地同步范围内的数据。没有自动、定时或后台同步。软件设置里的 MCP 工具 `upload_local_data` / `download_local_data` 走同一套手动快照，不另做自动同步。三种协议写入同一套快照格式，指向同一目录时可交叉恢复。

## 同步格式与兼容性

远端目录由应用维护，不要求用户指定或编辑文件名。当前 `formatVersion` 为 `1`，客户端只接受已知格式版本；格式或 JSON 不合法、认证失败、网络失败时，本地数据不会被修改。

```text
远端同步目录/
├── manifest.json      # 格式版本、生成时间、来源和文件清单
├── inventory-<时间戳>.json     # 账号元数据、遗器、光锥与角色录入数据
├── build-plans-<时间戳>.json   # 培养方案与毕业目标
└── teams-<时间戳>.json         # 本地配队（个人设置，非游戏数据）
```

每次上传都会生成一组带时间戳、不会覆盖旧版本的数据文件，全部成功后才更新 `manifest.json`。因此上传中断时，清单仍会指向上一次完整备份；下载先校验清单并读取所有必需文件，再在单个数据库事务中恢复。本应用后续新增独立同步领域时，会由代码新增固定文件并登记到清单中。

当前同步格式为 **v3**，新增了本地配队（`teams-*.json`）。v3 客户端可恢复旧 v1/v2 备份（旧备份无配队文件时按空配队恢复，并清空本机配队）；旧客户端不能读取 v3 备份，以避免它在后续上传时静默丢失新增字段。

| 分类                     | 是否同步 | 内容                                                                     |
| ------------------------ | -------- | ------------------------------------------------------------------------ |
| 账号元数据               | 是       | UID、开拓者信息                                                          |
| 已录入背包               | 是       | 遗器及全部副词条、光锥、角色、技能、行迹、忆灵等录入字段                 |
| 培养方案与毕业目标       | 是       | 套装、主词条、有效副词条、属性目标、优先级、最低值、仪表盘顺序与置顶状态 |
| 本地配队                 | 是       | 配队名称、备注、4 角色槽位（个人设置，非游戏直读数据）                   |
| 同步连接凭据             | 否       | 仅保存在当前设备                                                         |
| 界面本地偏好             | 否       | 例如行迹显示设置                                                         |
| 内置图鉴和静态参考数据   | 否       | 随应用版本提供                                                           |
| 导入运行记录、运行时状态 | 否       | 仅用于本机运行                                                           |

新增会持久化的业务数据时，必须先更新本表并决定其是否应加入同步快照；若加入，还要更新同步格式、恢复逻辑与兼容测试。
