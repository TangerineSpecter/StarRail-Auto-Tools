# 角色权重模板说明（供评审）

> **用途**：给同事审阅「培养方案 → 词条权重 → 角色模板」的设计思路与数值是否合理。  
> **实现源**：`src/shared/utils/relic-score/tables.ts` 中的 `DEFAULT_ROLE_WEIGHTS`（以代码为准；本文与代码同步编写）。  
> **评分用途**：Stat Score / 遗器筛选 / 预计刷本成本启发式，**不是**战斗伤害（Combat Score）或官方毕业表。

---

## 1. 这份文档要回答什么

1. 权重数字 **是什么意思**、怎么进评分。  
2. **九套模板**各自适用谁、完整权重表、为何这样分。  
3. 与 Fribbels 文档的关系、已知局限、请评审重点看什么。

## 2. 权重体系基础

### 2.1 取值范围

| 项目 | 约定 |
|------|------|
| 范围 | **0.0～1.0**（用户可手填任意小数，不限于 0.25） |
| 模板预设 | 多为 **0 / 0.25 / 0.5 / 0.75 / 1.0**，便于对齐社区习惯 |
| 0 | 该副词条 **不参与** 加权分（出现也不加分） |
| 1.0 | 该词条视为 **核心目标**（一条高 roll 贡献最大） |
| 0.5～0.75 | **有用但次于核心** |

### 2.2 评分时怎么用（评审需知）

对每条副词条大致：

```text
贡献 ≈ effectiveWeight(词条) × 品质折算后的 roll 数
```

- `effectiveWeight`：非小属性时 = 模板权重；**小攻/小生/小防** = **对应百分比权重 × 0.4**  
  （例：模板 `ATK%=0.75` → 小攻击按 `0.3` 计，无需在表里再写一行小属性。）  
- 因此下表只列 **12 条可出副属性键**（与游戏副词条池一致）；小属性不单独占一列。

### 2.3 十二项副词条键名（英文 = 代码 / 导入键）

| 键名 | 中文 | 一般含义（评分语境） |
|------|------|----------------------|
| SPD | 速度 | 行动条、配速断点；多数角色重要，**低速反击构筑例外** |
| CRIT Rate | 暴击率 | 直伤期望核心之一 |
| CRIT DMG | 暴击伤害 | 直伤期望核心之一 |
| ATK% | 攻击百分比 | 多数攻倍输出 / DoT / 部分击破 |
| HP% | 生命百分比 | 生命倍率输出 / 生存 |
| DEF% | 防御百分比 | 防御倍率输出 / 生存 |
| Effect Hit Rate | 效果命中 | 上 debuff / 异常；DoT 与虚无辅助 |
| Effect RES | 效果抵抗 | **抗控/抗 debuff**，通常 **不抬输出** |
| Break Effect | 击破特攻 | 击破/超击破伤害乘区 |
| HP / ATK / DEF | 小生命/小攻/小防 | 由对应 % 权重 ×0.4 自动计入，表中权重列对「%」生效即可 |

### 2.4 设计原则（请重点审）

1. **输出模板不计 RES**（=0）  
   避免「歪效果抵抗」抬高输出件分数。Fribbels 对 **辅助** 才给 RES 0.25、**生存** 0.50。  

2. **速度不是全员 1.0**  
   - 常规主 C / 辅助 / DoT / 击破：SPD=1（重视配速）。  
   - **低速反击**（克拉拉、云璃等）：SPD=0，避免把速度词条评成「好词条」。  

3. **「倍率」= 技能公式吃哪块面板**  
   - 生命倍率输出 ≠ 神秘「缩放系统」，= 伤害吃 HP%。  
   - 防御倍率同理。  

4. **模板是 archetype，不是角色 ID 表**  
   同角色可能有多构筑；模板只是快捷起点，保存后以用户改过的权重为准。  

5. **主 C 主轴对齐 Fribbels 文档**  
   典型暴击直伤：ATK% 0.75、SPD/CR/CD 1.0。

## 4. 各模板完整权重表与说明

下列数值均为 **当前代码默认值**。未写出的键在实现里也会补全为 **0**（`w()` 对 12 键填底）。

### 4.1 `critDps` — 暴击直伤

**定位**：常规直伤暴击主 C，行动靠自己的速度与配速。  
**对齐**：Fribbels 主 C 默认主轴。

| 词条 | 权重 | 说明 |
|------|------|------|
| SPD | **1.0** | 配速 / 行动次数，核心 |
| CRIT Rate | **1.0** | 暴击期望核心 |
| CRIT DMG | **1.0** | 暴击期望核心 |
| ATK% | **0.75** | 有用，但单 roll 对伤通常略低于双暴（Fribbels 略降） |
| HP% | 0 | 非乘区，不计 |
| DEF% | 0 | 不计 |
| Effect Hit Rate | 0 | 一般不依赖命中 |
| Effect RES | **0** | 不抬输出分 |
| Break Effect | 0 | 非击破构筑 |

**小属性**：小攻按 ATK%×0.4=0.3；小生/小防为 0。

**适用举例**：巡猎/智识/毁灭等「双暴鞋或速度鞋 + 暴衣」常见路线。  
**不适用**：反击低速、纯击破、纯 DoT。

---

### 4.2 `critDpsSlow` — 低速反击输出

**定位**：伤害主要来自 **反击 / 被打触发**，主动轮次反而不是主力；希望 **相对慢**，多吃敌方行动。  
**调研依据**：克拉拉、云璃等社区构筑常 **攻击鞋、少堆 SPD**。

| 词条 | 权重 | 说明 |
|------|------|------|
| SPD | **0** | 速度词条通常不是目标；甚至可能减少受击窗口 |
| CRIT Rate | **1.0** | 仍靠暴击打伤害 |
| CRIT DMG | **1.0** | 同上 |
| ATK% | **1.0** | 脚部常走攻击鞋，攻击权重大于常规主 C 的 0.75 |
| 其余 | 0 | 含 RES/EHR/击破/生命%/防御% |

**评审点**：SPD=0 是否过绝对？若存在「微速微调」需求，可改为 0.25；当前取 0 是为避免把高 SPD 废件评高。

---

### 4.3 `hpDps` — 生命倍率输出

**定位**：技能伤害 **吃生命面板**（不是「生命缩放」系统名）。

| 词条 | 权重 | 说明 |
|------|------|------|
| SPD | **1.0** | 仍常追断点 |
| CRIT Rate | **1.0** | 直伤仍吃暴击 |
| CRIT DMG | **1.0** | 同上 |
| HP% | **1.0** | 核心乘区 |
| ATK% | **0** | 通常远弱于生命% |
| DEF% / EHR / RES / BE | 0 | — |

**适用举例**：刃等。具体角色若还吃攻击，用户可手调 ATK%。

---

### 4.4 `defDps` — 防御倍率输出

**定位**：少数 **防御乘区** 输出；与纯奶盾不同，仍保留双暴。

| 词条 | 权重 | 说明 |
|------|------|------|
| SPD | **1.0** | 配速 |
| DEF% | **1.0** | 核心乘区 |
| CRIT Rate | **0.75** | 有输出时仍要暴击，略低于纯双暴 C |
| CRIT DMG | **0.75** | 同上 |
| HP% | **0.25** | 少量生存/部分技能 |
| ATK% / EHR / RES / BE | 0 | — |

**评审点**：DEF 输出角色样本少，0.75 双暴是否合适可再议。

---

### 4.5 `breakDps` — 击破输出

**定位**：击破 / 超击破；伤害主要吃 **击破特攻**，多数构筑 **几乎不吃双暴**。

| 词条 | 权重 | 说明 |
|------|------|------|
| Break Effect | **1.0** | 核心 |
| SPD | **1.0** | 行动与破盾节奏 |
| ATK% | **0.75** | 部分击破角色仍吃攻击 |
| CRIT Rate | **0** | 主流击破不抬双暴 |
| CRIT DMG | **0** | 同上 |
| EHR / RES / HP% / DEF% | 0 | — |

**适用举例**：流萤、波提欧等方向。  
**评审点**：若某角色击破+直伤双修，应手填少量双暴，勿强行用本模板。

---

### 4.6 `dot` — 持续伤害 DoT

**定位**：异常 / 持续伤害与引爆；主吃 **攻击、速度、效果命中**。  
**适用举例**：卡芙卡、黑天鹅、桑博等。

| 词条 | 权重 | 说明 |
|------|------|------|
| ATK% | **1.0** | DoT / 引爆乘区 |
| SPD | **1.0** | 行动次数、引爆节奏 |
| Effect Hit Rate | **1.0** | 上异常/debuff 稳定性 |
| CRIT Rate | **0** | 多数 DoT 不吃双暴 |
| CRIT DMG | **0** | 同上 |
| BE / RES / HP% / DEF% | 0 | — |

**评审点**：黑天鹅等对命中要求极高，EHR=1 合理；若某 DoT 几乎满命中不需要 EHR，用户可自行下调。

---

### 4.7 `support` — 同谐/进攻辅助

**定位**：拉条、加攻、增伤、暴击 buff 等，**不依赖效果命中** 上 debuff。  
**适用举例**：布洛妮娅、花火、知更鸟等方向。

| 词条 | 权重 | 说明 |
|------|------|------|
| SPD | **1.0** | 几乎永远是第一优先（配速） |
| HP% | **0.5** | 生存，避免被秒 |
| DEF% | **0.25** | 次要生存 |
| Effect RES | **0.25** | Fribbels 进攻辅助口径：抗控，**不抬输出** |
| ATK% | **0.25** | 部分辅助技能/光锥吃攻击 |
| EHR | **0** | 不依赖命中时避免抬死词条 |
| 双暴 / 击破 | 0 | 一般不作为辅助词条目标 |

**评审点**：停云等吃攻击的辅助可手调 ATK%；需要命中的辅助请改用 `ehrSupport`。

---

### 4.8 `ehrSupport` — 命中/虚无辅助

**定位**：靠 **效果命中** 上减益 / 禁锢等。  
**适用举例**：佩拉、银狼、椒丘等方向。

| 词条 | 权重 | 说明 |
|------|------|------|
| SPD | **1.0** | 先手与循环 |
| Effect Hit Rate | **1.0** | 核心门槛属性 |
| HP% | **0.25** | 生存 |
| DEF% | **0.25** | 生存 |
| Effect RES | **0.25** | 抗控（辅助口径） |
| ATK% / 双暴 / 击破 | 0 | — |

---

### 4.9 `sustain` — 生存位（奶盾）

**定位**：治疗 / 护盾 / 承伤，保证队伍不死。  
**适用举例**：罗刹、藿藿、砂金偏生存构筑等。

| 词条 | 权重 | 说明 |
|------|------|------|
| SPD | **1.0** | 治疗/盾覆盖节奏 |
| HP% | **0.75** | 奶量/部分盾与生存 |
| DEF% | **0.75** | 生存 |
| Effect RES | **0.5** | Fribbels 生存位口径，抗控价值更高 |
| EHR | **0** | 非命中向生存 |
| ATK% / 双暴 / 击破 | 0 | — |

**评审点**：砂金等「盾+输出」双修可能要手加双暴；本模板偏纯生存。

## 6. 未配置权重时的自动推断（次要）

当方案 `substatWeights` 为空时：

- **评分 / TBP** 仍用 `resolvePlanWeights` → 按有效副词条推断（可错）。  
- **编辑器**只展示推断结果，**不写入** `substatWeights`；用户未改权重直接保存时，库中仍为空，继续走推断。  
- 用户选择模板或改任意数值后才 materialize 进方案，保存时持久化。

---

## 7. 速度断点（与模板的关系）

- **速度断点** = 玩家设定的 **总速度目标阈值**（如 134），用于估算「还差多少速」，**不是**模板里的 SPD 权重本身。  
- 模板 SPD=1：评分时 **重视速度词条**。  
- 模板 SPD=0：评分时 **速度词条不加分**（低速反击）。  
- 多数「越高越好」的角色：权重 1 + 自设断点；到达断点后继续堆速是否亏，Stat Score **不会自动降权**（已知局限）。

---

## 8. 已知局限（请评审时对照）

1. **非角色级精确表**，同角色多构筑需手调。  
2. **SPD 断点前后价值跳变**未建模（断点前满分、断点后接近 0）。  
3. **击破/DoT 双修、盾辅双修**等混合体要自定义权重。  
4. **版本迭代**会改变主流构筑，模板需偶尔重审。  
5. 评分 **不能**替代配队伤害模拟。  
6. 小属性 40% 规则全局统一，个别极端情况可能不准。
