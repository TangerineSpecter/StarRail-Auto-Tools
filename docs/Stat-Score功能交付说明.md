# Stat Score / Estimated TBP 功能交付说明

本文说明本轮交付的 **16 项能力** 分别在应用里 **去哪看、怎么用、怎么分析**。  
评分与预计开拓力均为 **启发式**，用于词条质量与刷本优先级；**不是**战斗伤害（Combat Score / DPS）。

配套理论文档：

- `docs/Stat-Score评分说明.md`
- `docs/Estimated-TBP理论说明.md`

算法实现（纯前端、可单测）：

- `src/shared/utils/relic-score/`

## 1. 评分内核

### 去哪看

代码：`src/shared/utils/relic-score/`  
测试：`tests/unit/relic-score.spec.ts`

### 怎么用

业务 UI 不直接写公式，统一调用：

- `scoreRelic` — 加权 rolls、潜力 %、字母等级、完美度
- `estimateTbp` — 期望开拓力 / 天数 / 建议
- `rerollPotential` — 重塑期望变化
- `averageCharacterPotential` / `farmingPriorityRows` / `planQualityCompletion` 等

### 怎么分析

- **加权 Rolls**：期望副属性 × 权重 × 品质（0.8/0.9/1.0）；小属性按 40%。
- **潜力 % / 字母**：相对同主属性理想件。错误可选主属性不给字母。
- **TBP**：同套同部位同主属性下刷到 **更高加权分** 的期望成本（解析近似，强化按中 roll 0.9）。
- **重塑 Δ**：当前完美度 vs 重塑后期望完美度。

## 2. 副属性权重编辑与持久化

### 去哪看

1. **数据管理** → 打开角色 → **编辑培养方案**，或
2. **毕业管理** → 某角色 **编辑目标**

区块标题：**词条权重 / Stat Score**

### 怎么用

- 选角色模板（暴击主 C / 生命缩放 / 防御 / 击破 / 辅助 / 生存）一键套默认权重。
- 每条副属性 0 / 0.25 / 0.5 / 0.75 / 1.0。
- **质量门槛 (潜力%)**：毕业完成度里「质量达标」的阈值（默认 40 ≈ A）。
- **速度断点目标**：写入方案，供 SPD 助手默认读取。
- **保存** 后写入 SQLite；**WebDAV 上传/下载会一并备份培养方案（含权重）**。

### 怎么分析

- 空权重时，评分按 **有效副词条** 推断；编辑器仅展示推断值，**不改就保存不会落库权重**（改数值或选模板后才写入）。
- 角色模板完整权重表与评审说明（可交给他人审）：`docs/角色权重模板说明.md`。

- 改权重会立刻影响详情评分、列表排序、刷本天数、扫描排序。
- 权重表达的是 **你在意什么词条**，不是伤害公式。

## 3. 遗器详情质量卡片

### 去哪看

**数据管理** → 遗器列表 → 点开一件 → 副属性下方 **词条质量** 卡片。

### 怎么用

- 若遗器已装备且该角色有培养方案，自动用该方案权重。
- 否则用默认推断权重。
- 只读展示，不改锁/弃置。

### 怎么分析

| 字段              | 含义                                  |
| ----------------- | ------------------------------------- |
| 字母等级          | 潜力档（F…AEON）；主属性不符可为 —    |
| 潜力 %            | 相对理想件完成度                      |
| 加权 Rolls        | 词条质量绝对值                        |
| 完美度            | 距理论满加权 rolls                    |
| 升级期望 / 开拓力 | 再刷更好的平均成本                    |
| 刷本建议          | 优先刷 / 可继续 / 可停刷 / 主属性不符 |
| 重塑期望          | Δ% + 文案（负 = 大概率变差）          |
| 分项 breakdown    | 各词条贡献                            |

**分析建议：** 字母高且天数很长 → 可当毕业件；字母低且天数短 → 优先刷该本。

## 4. 列表按加权质量排序 / 筛选

### 去哪看

**数据管理** → 遗器 Tab → 筛选栏下方 **词条质量排序与标签** 工具条。

### 怎么用

1. **评分方案**：选一个已有培养方案角色（或默认权重）。
2. **排序**：加权分高→低 / 低→高 / 高质量优先。
3. **最低字母等级**：例如 ≥ B。
4. 仅作用于 **当前已加载列表页**（非全库 SQL 排序）。

### 怎么分析

用于快速找到「对某角色看起来好/差」的件。分页之外的遗器需继续滚动加载后再排序。

## 5. 角色六件摘要 + 短板部位

### 去哪看

**数据管理** → 角色详情 → **六件质量 / 刷本优先级** 面板（在站街属性上方）。

### 怎么用

打开已装备遗器的角色即可；有方案时用方案权重与主属性表。

### 怎么分析

- **平均潜力 %**、各部位字母、**短板部位**（潜力最低）。
- 先补短板部位，通常比平均抬六件分更有效。
- 与 **站街属性** 并列：站街看面板数，本面板看词条期望。

## 6. 质量标签（锁定 / 继续刷 / 分解候选）

### 去哪看

遗器列表质量工具条：**预览质量标签** → **确认锁定建议… / 确认分解候选…**

### 怎么用

1. 先点 **预览**（仅统计，不写库）。
2. 再点确认查看清单。
3. **不会自动改 lock/discard**；需人工在列表操作。产品刻意避免误伤。

### 怎么分析

| 标签     | 大致规则                |
| -------- | ----------------------- |
| 建议锁定 | 潜力或加权 rolls 达门槛 |
| 可继续刷 | 中等，有期望提升空间    |
| 分解候选 | 很差或主属性不符方案    |

门槛来自方案的 `minPotentialPct`（默认 40）。

## 7. 方案完成度（主属性 + 质量）

### 去哪看

- 角色详情：主属性正确数 / 质量达标数 / 综合完成度
- **毕业管理** 卡片：`质量 x/y · 主属性 x/y · 词条完成 z%`

### 怎么用

在方案中设置 **各部位允许主词条** + **质量门槛** + 权重后保存。

### 怎么分析

- 主属性全对但质量低 → 该刷本，不是换主属性。
- 质量高但主属性错 → 先纠正主属性（错误主属性不评级）。
- 综合完成度 = 0.5×主属性比例 + 0.5×质量达标比例。

---

## 8. 刷本优先级表

### 去哪看

角色详情 **刷本优先级** 表格（部位 / 等级 / 加权 / 期望天数 / 建议）。

### 怎么用

对比六行建议：优先刷天数短且等级低的部位。

### 怎么分析

- **优先刷**：期望升级成本低。
- **可停刷**：天数很长或完美度已经很高。
- 天数是 **期望值**，不是保底。

## 9. 扫描器：替换推荐扫描

### 去哪看

导航 **背包扫描** → **替换推荐扫描**。

（原 **主属性扫描** 仍保留：找「主属性对不上任何方案」的闲置件。）

### 怎么用

1. 至少保存一个培养方案（含目标主属性与套装）。
2. 点 **替换推荐扫描**。
3. 只列出「对某方案：套装匹配 + 主属性匹配 + 副词条加权分严格高于该角色当前同部位」的未装备遗器。
4. 若没有更好的件，结果为空。

### 怎么分析

- 列表按相对当前穿戴的加权分增量排序；显示推荐角色、增量与双方 rolls。
- 空结果 = 当前未装备池里没有可替换升级件（在分析上限内）。
- 与主属性扫描互补：一个找「无目标主属性闲置」，一个找「能换上更好」的替换。

## 10–13. 部位替换 / SPD / 投入估计 / 轻量优化

### 去哪看

角色详情同一面板：

- **短板部位替换建议** → 「从背包检索可替换遗器」
- **速度断点助手**
- **投入估计**（及毕业卡片上的「投入估 N 天」）

### 怎么用

| 功能           | 操作                                                                                                            |
| -------------- | --------------------------------------------------------------------------------------------------------------- |
| 替换建议       | 加载背包（最多 200 件）→ 同部位同主属性且加权分更高的候选                                                       |
| SPD 助手       | 填目标速度，或方案里设 `spdTarget` / SPD 属性目标；有站街面板时用**总速度**对比目标，否则按缺口（gap-only）估算 |
| 刷本优先级     | 角色/遗器详情均需点击 **「计算刷本成本」** 后再算；毕业管理列表只展示轻量潜力/质量 chip                         |
| 替换推荐扫描   | 默认最多分析 200 件未装备遗器；套装+主属性匹配且词条分 > 当前穿戴才列出；超出时 UI 提示截断                         |
| 列表质量排序   | 仅当前已加载页；换 Tab 会清空客户端排序缓存                                                                     |
| 投入估计       | 自动：瓶颈部位天数 + 其余部位 25%                                                                               |

### 怎么分析

- 替换建议是 **增量同角色优化**，不是全局换套伤害优化。
- SPD 助手只根据 **遗器提供的速度加成** 估算还差多少 roll；角色基础速需自行心算。
- 角色级投入是粗算，用于「这角色还要养多久」的量级感。

## 15. WebDAV 与备份

### 去哪看

**软件设置** → WebDAV 上传/下载。

### 怎么用

培养方案字段现含：

- `substatWeights`
- `minPotentialPct`（允许 0；无效值存库时回落 40）
- `spdTarget`

**WebDAV**：随本地库存与方案一并备份；下载为 **整库替换**，不是合并。

**Excel 导入/导出**：会写出并读回  
「词条权重 JSON / 质量门槛 / 速度断点」（列 34–36，权重列默认隐藏）。  
旧版 Excel 无这些列时使用默认空权重 + 门槛 40。权重 JSON 仅接受英文键名与 0–1 数值。

### 怎么分析

换机后评分一致的前提：方案已保存且备份（WebDAV 或含扩展列的 Excel）包含最新方案。

## 16. 免责声明（产品约定）

应用内多处写明：

> 词条评分 / 预计开拓力是启发式，**不是**战斗伤害。

请勿：

- 把字母等级当 DPS 排名
- 把「44 天」理解成保底出货
- 未确认就批量弃置（当前也不会自动弃置）

请配合：

- 站街面板看面板数
- 实战与自己的配队理解做最终决策

## 数据字段（培养方案）

| 字段              | 说明                          |
| ----------------- | ----------------------------- |
| `substatWeights`  | `Record<string, number>`，0–1 |
| `minPotentialPct` | 质量达标门槛，默认 40         |

## 已知近似与非目标

- TBP 强化品质用 **中 roll 0.9** 近似，未做全 0.8/0.9/1.0 卷积（见理论文档）。
- 列表排序仅当前页；扫描有用度最多 200 件未装备遗器。
- **不做** 全量 Combat Score / 队伍 buff 优化。
- **不做** 自动锁定/弃置。

## 手动验收路径（Tauri 桌面）

1. 同步/导入背包与至少一个培养方案。
2. 编辑方案 → 套「暴击主 C」权重 → 保存。
3. 打开该角色已装备遗器 → 看质量卡片与六件摘要。
4. 遗器列表 → 选方案排序 → 预览标签。
5. 毕业管理 → 看质量/投入摘要。
6. 背包扫描 → 主属性扫描 + 替换推荐扫描。
7. WebDAV 上传后再下载，确认权重仍在。
